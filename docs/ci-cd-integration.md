# CI/CD integration

ComplianceKIbot.de is **CI/CD-native**: you can build compliance checks directly into your workflow.

## GitHub Action

Use the bundled **GitHub Action** to start a compliance scan on every push or pull request. The results (findings, risk score, legal mapping) appear as a **check run** directly in the pull request.

## GitLab CI template

The **GitLab CI template** does the same in GitLab: a pipeline job that runs a scan and delivers the evaluation into the merge-request view.

## VSCode extension

With the **VSCode extension** you start scans directly from the editor and see findings without leaving the pipeline — ideal for development.

## Why this is useful

An automated scan in the workflow makes compliance a **continuous check** instead of a one-off event. You catch violations before they reach production.
