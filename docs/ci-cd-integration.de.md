# CI/CD-Integration

ComplianceKIbot.de ist **CI/CD-nativ**: Sie können Compliance-Prüfungen direkt in Ihren Workflow einbauen.

## GitHub Action

Nutzen Sie die mitgelieferte **GitHub Action**, um bei jedem Push oder Pull-Request einen Compliance-Scan zu starten. Die Ergebnisse (Befunde, Risiko-Score, Rechtliche Zuordnung) erscheinen als **Check-Run** direkt im Pull-Request.

## GitLab-CI-Vorlage

Die **GitLab-CI-Vorlage** erledigt dasselbe in GitLab: ein Job in Ihrer Pipeline, der einen Scan ausführt und die Auswertung in die Merge-Request-Ansicht liefert.

## VSCode-Erweiterung

Mit der **VSCode-Erweiterung** starten Sie Scans direkt aus dem Editor und sehen Befunde ohne die Pipeline zu verlassen — ideal für die Entwicklung.

## Warum das nützlich ist

Ein automatisierter Scan im Workflow macht Compliance zur **kontinuierlichen Prüfung** statt eines einmaligen Ereignisses. Sie erkennen Verstöße, bevor sie in Produktion gehen.
